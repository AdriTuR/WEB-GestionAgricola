## Descripción

**Agricultura de Precisión** es una página web sobre sensores para la agricultura y el campo, desarrollada como proyecto para la asignatura de Diseño y Programación Web del Grado en Tecnologías Interactivas de la Universitat Politècnica de València (UPV). La plataforma permite a cada usuario o cliente gestionar sus parcelas y consultar la información de los sensores asociados. Complementa un sensor agricola que mide temperatura, humedad, salinidad e iluminación, y esta web muestra y gestiona esos datos a través de una base de datos y una API REST.

<br>

## Características Principales

* **Gestión de parcelas:** Cada usuario/cliente puede administrar sus parcelas y consultar la información de los sensores instalados en ellas.
* **Sistema de usuarios y login:** Autenticación de cuentas con base de datos MySQL, donde se almacenan los usuarios junto a los datos de sus parcelas.
* **Visualización de medidas:** Consulta de las lecturas enviadas por la sonda agrícola (temperatura, humedad, salinidad e iluminación), incluyendo gráficos de evolución.
* **Backend con API REST:** Lógica de servidor en PHP que expone y consume datos mediante servicios REST.
* **Contacto y solicitud de servicio:** Formulario para ponerse en contacto con la empresa y solicitar el servicio de sondas.
* **Diseño responsive:** Interfaz adaptada a distintos dispositivos, pensada para un uso sencillo e intuitivo.
